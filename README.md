# خلوت (Khalvat) — طراحی شده توسط Mr.PC

پروژه Android Studio (Kotlin + Jetpack Compose).

## اجرا
1. Android Studio (نسخه Ladybug یا جدیدتر) را باز کنید و پوشه پروژه را Open کنید.
2. صبر کنید Gradle Sync تمام شود (نیاز به اینترنت برای دانلود کتابخانه‌ها).
3. روی گوشی واقعی اندروید ۱۰ یا بالاتر اجرا کنید (شبیه‌ساز تماس واقعی ندارد).
4. در داشبورد برنامه، بخش «راه‌اندازی» را کامل کنید:
   غربالگر تماس، مخاطبین، دریافت پیامک، دسترسی اعلان‌ها.

## بخش‌ها
- داشبورد، قوانین تماس، قوانین پیامک، مخاطبین و فرستنده‌ها، آرشیو، تنظیمات، درباره
- قوانین: هدف (همه / فقط انتخاب‌شده / همه به‌جز انتخاب‌شده)، روز هفته، ساعت، بازه تاریخ،
  رفتار (بی‌صدا / رد / پنهان‌کردن اعلان) و تاریخچه (بماند / آرشیو / حذف کامل)
- حالت تمرکز، مخاطب ویژه، قفل بیومتریک، دیتابیس رمزنگاری‌شده، حذف خودکار آرشیو

## نکته
این پروژه هنوز روی دستگاه واقعی تست نشده است. اولین Sync ممکن است نیاز به
اصلاح جزئی نسخه‌ها داشته باشد.
